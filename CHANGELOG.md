# Historial de versiones

## 1.1.0 - versión web

- Paquete preparado para GitHub Pages.
- Flujo automático de despliegue mediante GitHub Actions.
- Manifest ampliado con accesos directos, capturas e iconos para instalación.
- Icono Apple Touch de 180 px.
- Ayuda de instalación para Android, iPad/iPhone y escritorio.
- Botón de instalación contextual.
- Aviso y aplicación controlada de nuevas versiones.
- Estrategia offline con caché versionada.
- Estado de conexión, HTTPS, uso offline y almacenamiento persistente.
- Ajustes de áreas seguras para pantallas móviles.
- Compatibilidad con publicación en una subcarpeta de GitHub Pages.
- Base de datos y formato de respaldo conservados en versión 2.

## 1.0.0

- Teoría, improvisación y lectura a primera vista.
